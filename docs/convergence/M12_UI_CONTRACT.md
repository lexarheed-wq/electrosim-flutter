# M12 — Interface Flutter finale

## Principes

- barre supérieure compacte ;
- Accueil, Tableau de bord et Gérer la session restent visibles dans les sessions ;
- Rotation et Supprimer restent des actions uniques proches de la platine ;
- Sauvegarder, Reprendre et Recentrer sont regroupés dans « Plus d'actions » ;
- palette : cinq composants rapides au maximum, recherche et catégories pour le reste ;
- compact/mobile : canvas prioritaire, palette et propriétés en panneaux superposés ;
- medium : panneau latéral à la demande ;
- desktop : palette, canvas et contexte simultanés.

La structure est compatible avec une comparaison Figma ultérieure. Aucun fichier Figma n'étant attaché à la conversation, la qualification M12 repose sur les contraintes Flutter et les tests responsive.
