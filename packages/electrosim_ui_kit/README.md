# electrosim_ui_kit — F9

Package Flutter de présentation partagé ouvert après validation physique de F8.

F9-R2 fournit uniquement :

- tokens sémantiques et couleurs électriques séparées ;
- thème clair initial ;
- classification responsive compact / medium / expanded ;
- surfaces/panneaux de base ;
- shell simulateur responsive qui conserve le Canvas comme surface dominante.

Le package ne dépend d'aucun solveur, d'aucun moteur électrique et d'aucun `CircuitState`.
