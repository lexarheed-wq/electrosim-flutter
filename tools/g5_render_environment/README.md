# Offline studio illumination

`studio_small_09_1k.hdr` is the **Studio Small 09** HDR environment from [Poly Haven](https://polyhaven.com/a/studio_small_09), distributed under [CC0](https://polyhaven.com/license).

Downloaded from https://dl.polyhaven.org/file/ph-assets/HDRIs/hdr/1k/studio_small_09_1k.hdr. It is used only by the offline Blender renderer to produce realistic metal reflections, not loaded by Flutter.
