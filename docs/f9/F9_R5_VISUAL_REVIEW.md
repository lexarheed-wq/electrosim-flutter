# F9-R5 — Revue visuelle physique

Source : enregistrement macOS fourni après `F9_R5_GATE_PASS`.

## Résultat

La navigation F9-R5 est fonctionnelle sur macOS :

- accueil avec les trois entrées validées ;
- ouverture d'une session active ;
- navigation persistante Accueil / Tableau de bord / Gérer la session ;
- changement d'espace via Tableau de bord ;
- dialogue Gérer la session ;
- accès direct Centre de maintenance ;
- accès direct Centre de conception ;
- Canvas F8 stable dans le shell ;
- aucun crash ni overflow visible dans la séquence fournie.

## Écarts non bloquants relevés

- la palette reste un prototype à trois éléments ;
- le texte `Palette F9-R4 — identité visuelle initiale` est obsolète dans R5 ;
- `Glisser/déposer : lot F9.3` annonce encore une capacité non implémentée ;
- l'espace Supervision utilise encore le shell/Canvas commun comme placeholder.

Les trois premiers points sont traités par F9-R7. L'écran métier de Supervision sera traité dans le lot métier correspondant et ne doit pas introduire de calcul électrique dans l'UI.
